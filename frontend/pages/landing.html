What the platform monitors

Fraud signals that are easier to understand.

The app connects transaction-level ML with graph structure, anomaly detection, and readable alert reasons.

ML

Balanced fraud model

RandomForest training uses class weighting, balanced samples, validation plots, and a tuned threshold.

NX

Graph intelligence

Accounts become nodes, transactions become weighted edges, and communities reveal suspicious clusters.

IF

Anomaly detection

Isolation Forest catches unusual transaction amounts and adds runtime evidence to the risk score.

DB

Account reputation

SQLite stores users, transaction history, alert activity, and account-level risk summaries.

EX

Explainable alerts

Dashboards show why a transaction was flagged, including amount, type, frequency, and graph context.

UI

Live dashboards

User and admin pages display risk trends, analytics charts, transaction tables, and the PyVis graph.

Pipeline

Dataset to prediction flow.

1. Preprocess Clean PaySim rows and encode transaction types.
2. Build graph Model sender and receiver accounts as a directed network.
3. Engineer features Add degree, PageRank, clustering, frequency, and amount totals.
4. Score risk Run model probability, custom threshold, and anomaly checks.
5. Explain Store risk level, alerts, graph updates, and readable reasons.
